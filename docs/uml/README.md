# UML diagrams for COLORS

This directory contains the three required UML diagrams: use case, activity, and class/module.

| Diagram | Editable PlantUML source | Rendered diagram |
|---|---|---|
| Use Case | [usecase.puml](usecase.puml) | [usecase.svg](usecase.svg) |
| Activity | [activity.puml](activity.puml) | [activity.svg](activity.svg) |
| Class / Module | [class.puml](class.puml) | [class.svg](class.svg) |

The web application implements login, restoration of client-side cookie values, color searching, adding a color, and logout. It does not include signup, editing colors, or deleting colors. The "class" view shows JavaScript module functions, PHP endpoints, and inferred database tables; they are not all actual object-oriented classes. Verify the inferred SQL table fields against your deployed database.

All three SVG files are fully rendered images viewable directly on GitHub. The *.puml sources can be edited and rendered through PlantUML.
